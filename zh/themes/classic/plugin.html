插件配置

你可以通过 themePlugins 设置经典主题使用的插件。

经典主题使用了一些插件，如果你确实不需要该插件，你可以选择禁用它。在禁用插件之前，请确保你已了解它的用途。

.vuepress/config.ts
import { classicTheme } from '@vuepress/theme-classic'

export default {
  theme: classicTheme({
    themePlugins: {
      // 在这里自定义主题插件
    },
  }),
}

themePlugins

activeHeaderLinksboolean
默认值true

是否启用 @vuepress/plugin-active-header-links。

backToTopBackToTopPluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-back-to-top。

支持对象格式以作为插件选项。

copyCodeCopyCodePluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-copy-code。

支持对象格式以作为插件选项。

gitGitPluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-git。

hintMarkdownHintPluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-markdown-hint。

参考：提示容器

linksCheckLinksCheckPluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-links-check。

支持对象格式以作为插件选项。

mediumZoomboolean
默认值true

是否启用 @vuepress/plugin-medium-zoom。

nprogressboolean
默认值true

是否启用 @vuepress/plugin-nprogress。

prismjsPrismjsPluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-prismjs。

seoPartial<SeoPluginOptions> | boolean
默认值true

是否启用 @vuepress/plugin-seo。

支持对象格式以作为插件选项。

sitemapPartial<SitemapPluginOptions> | boolean
默认值true

是否启用 @vuepress/plugin-sitemap。

支持对象格式以作为插件选项。

tabMarkdownTabPluginOptions | boolean
默认值true

是否启用 @vuepress/plugin-markdown-tab。

参考：代码选项卡 与 选项卡
