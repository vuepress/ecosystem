markdown-math

Add math support to your VuePress site.

This plugin allows you to use mathjax or katex to render TeX\TeXTE​X in your markdown content.

Usage

npm i -D @vuepress/plugin-markdown-math@next

# install one of the following packages:
npm i -D @mathjax/src
npm i -D katex
.vuepress/config.ts
import { markdownMathPlugin } from '@vuepress/plugin-markdown-math'

export default {
  plugins: [
    markdownMathPlugin({
      // options
    }),
  ],
}

Options

type'katex' | 'mathjax'

The package to render TeX\TeXTE​X contents.

  • 'katex': use KaTeX
  • 'mathjax': use MathJax

When this option is not specified, the plugin will try to detect which package is installed. If both are installed, it will use "mathjax".

delimiters'brackets' | 'dollars' | 'all'
Default'dollars'

Math delimiter syntax to enable.

  • 'brackets': Use \(...\) for inline math and \[...\] for display math (LaTeX style).
  • 'dollars': Use $...$ for inline math and $$...$$ for display math (common Markdown style).
  • 'all': Enable both bracket and dollar syntaxes.

Using KaTeX

When using KaTeX, any other options will be passed to KaTeX as KatexOptions. See KaTeX Docs for all available options.

Besides, 2 special options are supported:

copyboolean

Whether to enable copy extension.

mhchemboolean

Whether to enable mhchem extension.

Using MathJax

When using MathJax, you can set:

texobject

Options passed to TeX input parser.

output'svg' | 'chtml'
Default'svg'

Output format, either SVG or Common HTML.

chtmlobject

Options passed to Common HTML output parser.

svgobject

Options passed to SVG output parser.

preloadDynamicFontsboolean
Defaulttrue

Whether to preload all dynamic font files of the selected output when the MathJax instance is created. render() is synchronous, so keep it enabled unless you provide a custom asyncLoad loader (an advanced option of @mdit/plugin-mathjax-slim) that resolves those files synchronously, or you only render glyphs from already loaded font groups.
