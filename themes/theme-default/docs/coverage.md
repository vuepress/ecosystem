# VitePress 默认主题功能覆盖

本主题只实现 VitePress 默认主题的**布局与样式**，并遵循 VuePress 生态约定：主题只负责布局，功能由插件提供。下表逐项列出 VitePress 默认主题的功能在本主题中的对应实现。

图例：**主题** —— 由本主题自身提供（布局或样式）；**插件** —— 由生态已有插件提供（主题已接线，或由用户自行启用）；**缺失** —— 暂未覆盖，并给出补全计划。

## 说明

- 主题只在导航栏挂载一个 `<SearchBox v-if="hasSearchBox" />`，不自带任何搜索实现、索引、worker 或语言数据——这些都属于搜索插件。
- 复制代码插件的选择器为 `selector: '[vp-content] div[class*="language-"] pre'`，因为主题的内容根节点带有 `vp-content` 属性，与生态插件的选择器约定一致。
- `@vuepress/plugin-medium-zoom` 与 `@vuepress/plugin-nprogress` 和 theme-default 一样默认启用；`medium-zoom` 的默认选择器已匹配 `vp-content` 内容根。
- `@vuepress/plugin-icon` 的 `offline` / `scan` 等配置可通过主题选项 `icon` 透传；主题默认使用在线模式，不要求用户安装图标集包。
- 提示容器由 `@vuepress/plugin-markdown-hint` 解析、渲染并自带样式（`.hint-container`，每个容器带图标，`details` 为原生可折叠元素）。主题不写容器样式：它引入 `@vuepress/helper/colors.css` 提供插件依赖的调色板，再在 `styles/vars.css` 里覆盖 `--hint-font-size` 等少量 CSS 变量。`v-pre`、`raw` 两个 VitePress 扩展分别由 `@vuepress/plugin-markdown-ext`（`vPre: true`）与 `@vuepress/plugin-markdown-raw` 提供；主题为 `raw` 默认开启样式隔离（VitePress 需要站点手动 opt-in），并在捕获阶段接管容器内链接的点击以绕过 SPA 路由，主题本身不再注册任何 Markdown 容器解析器（见[差异](./differences.md)）。代码组由 `@vuepress/plugin-markdown-tab` 提供（`codeTabs: true`），主题本身不注册 Markdown 解析器。
- 图标由 `@vuepress/plugin-icon` 提供（在线 iconify Web Component 模式）：主题不再于构建期生成图标 CSS，也不依赖 `@iconify-json/*` 包。代价是首屏 HTML 中图标为空、hydrate 后才出现，且依赖图标服务可用；需要构建期图标的站点可改用插件的离线模式（站点需自行安装 `iconify-icon` 与对应的 `@iconify-json/<prefix>`）。
- 主题只注册 `Layout` 与 `NotFound` 两个布局，页面类型由主题自己的 frontmatter 字段 `type` 决定：`home` 渲染首页、`doc`（默认）渲染文档页、`page` 渲染空白页面容器、`content` 只渲染页面内容而不渲染布局外壳。组件的判断统一走 `usePageType()`（`useLayout().isHome`、`Layout.vue`、`VPContent.vue`），`extendsPage` 不再改写 `layout`。`layout` frontmatter 只用于指定已注册的布局名（自定义布局、`NotFound`）；`NotFound` 必须单独注册：VuePress 核心在 `extendsPage` 之后才给内置 `/404.html` 设置 `frontmatter.layout = 'NotFound'`。
