Extending

VuePress classic theme is widely used by users, so it is designed to be extendable, allowing users to make their own customization with ease.

Layout Slots

Classic theme's Layout provides some slots:

  • navbar
  • navbar-before
  • navbar-after
  • sidebar
  • sidebar-top
  • sidebar-bottom
  • page
  • page-top
  • page-bottom
  • page-content-top
  • page-content-bottom

With the help of them, you can add or replace content easily. Here comes an example to introduce how to extend classic theme with layout slots.

Create a client config file and a local layout, and register the layout in the former:

.vuepress

client.ts

layouts

Layout.vue

client.ts
import { defineClientConfig } from 'vuepress/client'

import Layout from './layouts/Layout.vue'

export default defineClientConfig({
  layouts: {
    Layout,
  },
})
layouts/Layout.vue
<script setup>
import ParentLayout from '@vuepress/theme-classic/layouts/Layout.vue'
</script>

<template>
  <ParentLayout>
    <template #page-bottom>
      <div class="my-footer">This is my custom page footer</div>
    </template>
  </ParentLayout>
</template>

<style lang="css">
.my-footer {
  text-align: center;
}
</style>

Then the default Layout layout has been overridden by your own local layout, which will add a custom footer to every normal pages in classic theme (excluding homepage):

Components Replacement

The layout slots are useful, but sometimes you might find it's not flexible enough. Classic theme also provides the ability to replace a single component.

Classic theme has registered alias for every non-global components with a @theme prefix. For example, the alias of HomeFooter.vue is @theme/HomeFooter.vue.

Then, if you want to replace the HomeFooter.vue component, just override the alias in your config file .vuepress/config.ts:

.vuepress/config.ts
import { classicTheme } from '@vuepress/theme-classic'
import { defineUserConfig } from 'vuepress'
import { path } from 'vuepress/utils'

const __dirname = import.meta.dirname

export default defineUserConfig({
  theme: classicTheme(),
  alias: {
    '@theme/HomeFooter.vue': path.resolve(
      __dirname,
      './components/MyHomeFooter.vue',
    ),
  },
})

Modifying Behavior

Most of the core behaviors of the classic theme have been extracted into a composable API or util function, and also provide aliases with the @theme prefix.

For example, if you want to add some default values ​​to the theme data of the classic theme, you can override the useThemeData function of @theme/useThemeData.

Developing a Child Theme

Instead of extending the classic theme directly in .vuepress/config.ts and .vuepress/client.ts, you can also develop your own theme extending the classic theme:

.vuepress/config.ts
import type { ClassicThemeOptions } from '@vuepress/theme-classic'
import { classicTheme } from '@vuepress/theme-classic'
import type { Theme } from 'vuepress/core'
import { path } from 'vuepress/utils'

const __dirname = import.meta.dirname

export const childTheme = (options: ClassicThemeOptions): Theme => ({
  name: 'vuepress-theme-child',
  extends: classicTheme(options),

  // override layouts in child theme's client config file
  // notice that you would build ts to js before publishing to npm,
  // so this should be the path to the js file
  clientConfigFile: path.resolve(__dirname, './client.js'),

  // override component alias
  alias: {
    '@theme/HomeFooter.vue': path.resolve(
      __dirname,
      './components/MyHomeFooter.vue',
    ),
  },
})
